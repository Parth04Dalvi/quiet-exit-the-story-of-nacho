# Quiet Exit

A browser-based 3D open-world story game. Complete cartel jobs, leave the crew to build a civilian life, then face Don Hector in the final chapter.

## Features

- Three story chapters with paid missions and five homes to choose from
- A 3D city with pedestrians, sidewalk patrols, streetlights, bins, traffic signals, and cars that stop for red lights
- Keyboard and touch controls

## Run

Open `index.html` in a modern browser with an internet connection. The game loads Three.js from jsDelivr.

## Controls

- **W / S**: Move
- **A / D**: Turn
- **E**: Interact
- **F**: Punch
- **Space / left-click**: Fire
- **R**: Reload
- **Shift**: Run
- **Esc**: Close a conversation
